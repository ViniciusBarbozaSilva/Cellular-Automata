# Cellular-Automata
Repositório para o projeto da disciplina Cellular Automata de Jonas Albuquerque, UFRPE
Simulação de Propagação Viral com Autômatos Celulares de Múltiplos Estados
Este projeto implementa uma simulação baseada em autômatos celulares com múltiplos estados para modelar a propagação de uma infecção viral em um tecido biológico. A lógica do sistema se inspira na resposta natural do corpo humano, com células passando por estágios como saudável, infectada, ativação imune e recuperação.
O modelo, as motivações e os resultados foram detalhados em um artigo no formato científico, que pode ser acessado [text](https://docs.google.com/document/d/1udtP183gPTj27Ex70yCLnHsGS6xcabrTlR0KzQmuKNk/edit?usp=sharing).
